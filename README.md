### Flagship Systems

#### [AlphaTiger](https://github.com/kshtomar/TigersDay) — Neural Wargame & Client MCTS Engine
An AlphaZero-inspired wargame simulating the historical Anglo-Mysore Wars, engineered for **100% in-browser execution with zero backend inference cost**:
- **State Compression:** Compact 148-bit boolean state vector across a 959-action space.
- **Client Inference:** PyTorch self-play networks exported and INT8-quantized to ONNX WebAssembly, executing Monte Carlo Tree Search directly on the client CPU.
- **P2P Multiplayer:** Low-latency WebRTC data channels via PeerJS with deterministic state sync.  
<sub>`PyTorch` `ONNX WebAssembly` `MCTS` `WebRTC` `FastAPI`</sub>

#### [Clinical AI Diagnostics](https://www.acsef.org/copy-of-acsef-2025) — Hallucination-Free Medical RAG
Diagnostic vision and clinical LLM pipeline developed during a Mayo Clinic research mentorship:
- **Vision:** YOLOv8 for sub-centimeter lung nodule detection in CT imaging.
- **Language:** Multi-stage retrieval-augmented generation (RAG) grounding Claude in verified clinical oncology literature, eliminating generative hallucinations.  
<sub>`Python` `YOLOv8` `Claude API` `RAG`</sub>
